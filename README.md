# Contencioso · protótipo do redesenho da navegação

Protótipo navegável com a proposta de redesenho da navegação. Abra pelo link do GitHub Pages deste repositório.

- **Começo:** `index.html` (Painel).
- **Casos completos:** `processo.html?id=24`, `?id=29`, `?id=4` e `?id=14`.
- **Arquivo único:** `Contencioso-Prototipo-Completo.html` traz tudo junto num arquivo só.
- **O que mudou:** as etiquetas tracejadas **Mudou** e **Novo** marcam cada mudança da experiência. Clique numa delas para ver o antes, o agora e o porquê. O botão **O que mudou**, no topo, liga e desliga as etiquetas.

**Dados:** os nomes de pessoas são fictícios. Motivos, responsáveis, valores e trechos dos autos são ilustrativos. Nenhuma ação é executada de verdade.
